# Keep the knowledge current

Use current source and actual host tools. When code/config/dependencies change, inspect affected owning files, update their map/flow/unknowns and checkpoint the task. Preserve human notes and historical evidence. Old timestamps do not establish freshness.

Record the compared source/version and actual checks. Native hashes not computed stay not_computed; an unused optional machine gate stays not_run_optional. Existing project-required gates remain mandatory. Optional freshness/index/graph helpers may be used only when requested/required and available; no Python installation is needed for native maintenance.

Mark graphs/snapshots stale when their source changes; do not fabricate a rebuild. Keep internal knowledge outside public document roots and avoid credentials/customer data. Use one coordinator for shared summaries; workers use task-local records. Back up or review changes before replacing existing knowledge, and never reset a vault as an upgrade shortcut.
